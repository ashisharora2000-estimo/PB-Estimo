# Claude Project Knowledge Repository

This folder contains the complete knowledge base and architectural standards for the **Oracle Cloud Project Planning & Commercial Estimation Engine (PB-Estimo)**.

## Knowledge Articles Included:

1. **`01-oracle-true-cloud-methodology.md`**
   * Oracle True Cloud Method (OUM) lifecycle (Wave 0 through Wave 5).
   * 30-column Smartsheet format specification.
   * Mandatory cross-workstreams and stage gate requirements.

2. **`02-commercial-governance-and-doa.md`**
   * Commercial pricing models ($145/hr blended rate, 30% onsite / 70% offshore).
   * Automated resource ramp-down logic (Build -> SIT -> UAT -> Cutover).
   * Delegation of Authority (DoA) Tiers 1, 2, and 3 risk triggers.

3. **`03-ai-savings-and-baseline-variance-policy.md`**
   * Phase-wise AI acceleration benchmarks (Build: 35%, SIT: 25%, Discovery: 20%).
   * Quality floors for UAT and Cutover.
   * Excel baseline variance parsing formulas and SteerCo defense strategies.

4. **`04-indirect-procurement-and-scm-scoping.md`**
   * Functional boundaries for Purchasing, Self-Service Procurement (SSP), Sourcing, Contracts, SQM, and Supplier Portal.
   * Punchout cXML catalogs, approval matrix complexities, and SCM integrations.

5. **`05-system-architecture-and-estimation-math.md`**
   * P50 vs. P80 Monte Carlo confidence models.
   * 20-Question functional scoping multipliers.
   * Technical scale drivers (OIC integrations, BIP/OTBI reports, FBDI mock conversion loads).
